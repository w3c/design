# W3C Design

A Team-only task force between W3C's Systems Team and Communications Team focused on several aspects of the W3C design (such as templates, mock-ups, style-guide, proposals and design-related questions). This work was subsumed by the 2019 Website redesign which culminated in the [2023 redesign](https://www.w3.org/blog/2023/new-w3c-website-deployed/) and the adoption of the [W3C Design System](https://design-system.w3.org/).
